## 📋 Overview

**Mins Hospital** is the official website for a home healthcare service provider, showcasing services, care offerings, and a content/blog section for patient education. Built and maintained by **[Codesudio](https://www.codesudio.com)**.

---

## ✨ Features

| Feature | Description |
|---|---|
| 🏥 **Service Pages** | Overview of home healthcare offerings and specialties |
| 📝 **Blog / Content** | Health articles and patient-facing content |
| 📱 **Responsive Design** | Fully responsive across mobile, tablet, and desktop |
| ⚡ **Fast & SEO-Friendly** | Built on Next.js for performance and search visibility |

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/pkmbilal/Mins-Hospital.git
cd Mins-Hospital
```

### 2. Install dependencies

```bash
npm install
```

### 3. Run the development server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to see the result. 🎉

You can start editing the page by modifying `app/page.js` — the page auto-updates as you edit.
